# Story Weaver Studio

Create a story creator app. The app will take the following inputs:  image of the  main character, and a line from the story. The app will use the character illustration style and color palette and create a page for the story. IF needed, I must be able to provide multiple background images to create background using the similar color pallette and illustration style. The page layout is is an image with 16:9 resolution. On the left is the image and on the right is the  line of the text
